# 💼 Personal Portfolio Website – Assignment 11

## 📌 Project Overview

This project is a modern and visually appealing **Personal Portfolio Website** designed to introduce a Frontend Developer and showcase their professional identity, skills, projects, and experience.

The website features a clean dark-themed interface with a beautiful purple color palette, Arabic right-to-left (RTL) layout, and an attractive hero section that creates a strong first impression.

## ✨ Features

- **Modern UI Design:** Elegant dark theme with purple gradient-inspired accents.
- **RTL Layout:** Arabic interface with right-to-left text direction.
- **Navigation Bar:** Easy navigation between Home, About, Projects, Experience, Recommendations, and Contact sections.
- **Hero Section:** A welcoming introduction with the developer's name, profile image, and professional title.
- **Availability Status:** Displays the developer's availability for freelance work.
- **Call-to-Action Buttons:** Quick access to projects and contact information.
- **Interactive Elements:** JavaScript-powered interactions and user interface functionality.
- **Responsive Design:** Designed with a modern layout suitable for different screen sizes.

## 🛠️ Technologies Used

The project was built using:

- **HTML5:** Structuring the website content and layout.
- **CSS3:** Styling, layout, colors, animations, and visual effects.
- **JavaScript (ES6):** Adding interactivity and dynamic functionality.

## 🎨 Design Highlights

- Dark navy background.
- Purple accent colors.
- Circular profile image with glowing border effects.
- Floating technology icons.
- Modern typography and elegant spacing.
- Smooth and visually appealing interface.
